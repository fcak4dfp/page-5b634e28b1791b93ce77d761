使用场景

跨境办公与远程协作

视频会议、云文档与代码仓库访问对延迟和丢包敏感。小飞机把办公常用线路单独分组，配置流程里建议先测延迟再固定节点，避免会议中途跳线。

流媒体与资料检索

基础版覆盖常见点播解锁；旗舰版强调全节点原生解锁，减少验证失败。学术站点、公开课与软件更新也可走加速节点，但仍需遵守当地与平台条款。

游戏与实时对战

旗舰版提供 IPLC 游戏优化，适合对延迟稳定有要求的玩家。团队版则把带宽与设备数放开，方便工作室或多设备家庭共用一条订阅。

配置流程（操作说明）

小飞机的使用可以概括为五步：选套餐、拿到订阅、安装客户端、导入并更新、选择节点连接。请按顺序完成，不要跳过更新订阅这一步。

第一步：确认套餐与设备数量

先数清需要同时在线的手机、电脑和平板。3 台以内选基础版，5 台以内选旗舰版，工作室或家庭共享选团队版。流量以当月累计出站为准，下载客户端本身不计入套餐流量。

第二步：在官网完成订阅

登录小飞机官网会员中心后选择对应档位。支付成功后，面板会生成一条订阅地址。请只在本机密码管理器或加密笔记中保存，不要把订阅发到公开群组。

第三步：下载对应系统的客户端

前往本页客户端下载区，按系统选择官方推荐应用。Windows 与 macOS 使用桌面核心客户端，Android 与 iOS 使用移动端。同一订阅可在设备上限内多端导入。

第四步：导入订阅并更新节点

  1. 打开客户端，找到订阅或配置文件入口。
  2. 粘贴官网提供的订阅地址，命名为「小飞机」以便识别。
  3. 点击更新，确认节点列表刷新成功。
  4. 若列表为空，检查系统时间是否准确，再重试一次更新。

第五步：选节点、开启系统代理并验证

日常网页可选普通线路；会议与游戏改走低延迟或 IPLC 分组。开启系统代理或 VPN 模式后，用浏览器访问目标站点验证。若某条线路不稳定，在客户端内切换同分组其他节点即可，无需重新导入。

更换套餐或重置订阅链接后，必须在所有设备上重新更新一次。旧链接会在短时间内失效，这是为了避免分享外泄。

客户端官方下载

请从本站指引进入下载区，避免使用来路不明的安装包。桌面端负责系统代理与规则分流，移动端负责随时连接。导入同一条小飞机订阅后，设备数仍受套餐限制。

  • Windows 桌面客户端：适合长期挂机与规则分流。
  • macOS 桌面客户端：与系统网络设置协同，会议前先测延迟。
  • Android 客户端：建议锁定后台，以免系统休眠断开。
  • iOS 客户端：通过官方渠道获取，导入订阅后开启 VPN 配置。

安装完成后回到配置流程第四步导入订阅。小飞机不通过邮件群发安装包，若收到陌生下载链接请忽略。

常见问题

小飞机是什么？和普通加速器有何不同？

小飞机是提供机场订阅与多端客户端的网络加速服务。它把节点、流量与设备数打包进套餐，并在官网给出从下载到导入的完整配置流程，而不是只给一句“连接即可”。

如何完成第一次配置？

按本页配置流程：选套餐、复制订阅、下载官方客户端、粘贴并更新、选择节点后开启代理。任何一步失败，优先检查系统时间和是否用了过期链接。

客户端下载是否必须走官网？

是。只有官网列出的客户端能正确识别小飞机订阅格式并及时更新节点。第三方修改版可能造成账号异常或无法解锁流媒体。

基础版、旗舰版和团队版怎么选？

轻度浏览与基础点播选基础版；需要原生流媒体、游戏 IPLC 与优先工单选旗舰版；超过 5 台设备或需要定制路由选团队版。年付价格见各卡片说明。

流量用完或设备超限会怎样？

当月流量用尽后加速会降速或暂停，下个自然月重置。同时在线超过套餐台数时，新设备无法握手。可升级档位或下线空闲设备。

节点连不上时如何排查？

先更新订阅，再换同分组其他节点；确认本地网络可访问官网；关闭重复开启的系统 VPN。若仅某一地区线路异常，改用备用分组即可。

团队版如何做简单路由分工？

可在客户端为办公、流媒体、游戏设置不同策略组，把对应域名或应用指到 VIP 节点。具体规则字段以客户端说明为准，小飞机侧提供专属客户经理协助核对设备数。
